# Louie Smith - Portfolio

Projeto de site de portfólio fotográfico desenvolvido com HTML e CSS, com foco no aprendizado de **Flexbox** e construção de layouts multi-páginas.

---

## Descrição

Este projeto simula um site de portfólio de um fotógrafo profissional chamado **Louie Smith**. O site contém múltiplas páginas e uma estrutura completa de navegação, com foco na organização de layout utilizando Flexbox e estilização moderna com CSS puro.

---

## Funcionalidades

- Site multi-páginas (Home, Blog, Collection, About, Services e Contact)
- Layout com sidebar fixa de navegação
- Estrutura organizada com Flexbox
- Galeria de imagens estilo Instagram
- Página de blog com cards de postagens
- Footer com seções informativas (arquivos, fotos recentes e contato)
- Efeitos de hover em links e imagens
- Newsletter e áreas interativas visuais

---

## Tecnologias

- HTML5
- CSS3
- Flexbox
- Google Fonts
